One demo pattern

Watch code move without authority moving with it.

This toy workflow shows one way to evaluate generated PTC-Lisp across environments with different code, data, tools, and permissions. It is an example of the runtime primitives, not a required architecture.

What this example actually uses. Evaluation outcomes return directly to the workflow, which inspects them and chooses the next action. Its evidence mission exposes fixed toy functions representing the failure and changed page; it does not query the recorded trace. A different workflow could read trace evidence only when the host explicitly grants that capability.
